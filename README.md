# کمچه

دموی فارسی و روشن بازار نیروی اجرایی و طراحی ساختمان، با Flutter برای وب و اندروید.

مراحل ۱ تا ۶ پلن جدید: مدل‌ها و مخزن پروفایل، دسته‌های اجرا و طراحی، خانه با درخواست‌ها و پروفایل‌های مستقل، ورود نمایشی و پذیرش قوانین نسخه‌دار، پروفایل مشترک فرد/شرکت و اعضای اکیپ با دعوت و تأیید و حذف همراه اعلان.

## امتحان دمو

- صفحه من ← مشاهده حساب نمونه ← اعضا و دعوت‌ها.
- یک عضو تأییدشده و یک دعوت منتظر تأیید موجود است.
- با «حساب‌های نمونه» به حساب عضو دعوت‌شده بروید، دعوت را بپذیرید یا رد کنید و به حساب قبلی برگردید.
- حذف لینک توسط دعوت‌کننده بدون تأیید عضو انجام می‌شود و در اعلان‌های عضو دیده می‌شود.
- عضویت در چند اکیپ و داشتن اکیپ خود مجاز است. لینک مستقیم برگشتی و دعوت تکراری ممنوع‌اند.
- ورود نمایشی با شماره و کد `123456` است؛ حساب جدید پذیرش قوانین آزمایشی را لازم دارد.
- اطلاعات هر نصب مستقل است و با رفرش پاک می‌شود. پیامک، دیتابیس سرور، پیام‌رسانی واقعی، کش پایدار و لینک عمومی واقعی هنوز وجود ندارند.

## ساختار

`lib/core.dart` مدل‌های پایه و مرز مخزن و قواعد اکیپ را مستقل از صفحه نگه می‌دارد. `lib/kamcheh_ui.dart` خانه، پروفایل‌های مستقل و اکیپ را نمایش می‌دهد. `lib/user_profile.dart` شناسه پروفایل، فرد/شرکت و آمادگی را نگه می‌دارد. فایل‌های دیگر اجزای دموی قبلی‌اند و در مراحل مربوط تطبیق داده می‌شوند.

## اجرا و بررسی

```sh
flutter pub get
flutter analyze
flutter test test/kamcheh_test.dart
flutter run -d chrome
flutter build web --no-web-resources-cdn
```

SDK محلی Flutter 3.47.6 است. آزمون‌های kamcheh_test.dart مربوط به دامنه جدیدند. آزمون‌های قدیمی هشت‌دسته‌ای برای مرجع موجودند و نیاز به تطبیق دارند؛ نتیجه اجرای مجموعه قدیمی ادعای این مرحله نیست.

## انتشار و آینده

فقط پوشه اپ وارد مخزن گیت‌هاب شود؛ اسناد سرمایه‌گذاری پوشه بالاتر و اطلاعات خصوصی متعلق به مخزن کد نیستند. کلید امضا و فایل‌های محیطی وارد مخزن نشوند.

APK و وب قابل اشتراک در بسته انتشار تست آماده می‌شوند. سایت و اپ در آینده به یک بک‌اند و دیتابیس مشترک سرور متصل خواهند شد. گیت‌هاب میزبان دیتابیس زنده نیست. متن قوانین فعلی برای دمو است؛ قوانین نهایی پیش از عرضه واقعی آماده می‌شوند.
